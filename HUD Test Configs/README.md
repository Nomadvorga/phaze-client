# Конфиги HUD из тестовой матрицы

Восстановлены из двух исходных раскладок с параметрами итогового теста.
Старые тестовые файлы были удалены; это заново созданные профили, не сохранённые
runtime-конфиги после измерений. Исходные координаты и настройки остальных
функций взяты из оригиналов, SHA-256 которых совпал с использованным при тесте.

## Основная матрица — 18 файлов

- `x1` — маленькая исходная раскладка, масштаб HUD 1.
- `x3` — большая исходная раскладка, масштаб HUD 3.
- `blur` — радиус размытия 32.
- `gradient` — градиент со скоростью 4.
- `rounding` — скругление 10.
- `plain_background` — обычный фон Vanilla, без трёх эффектов.
- `background_off` — фон выключен, сами HUD остаются включёнными.

Например, `blur_gradient_rounding_x3.Phaze` включает все три эффекта при 3×,
а `gradient_x1.Phaze` — только градиент при 1×.

HUD Optimizer включён: Refresh Rate 10, Blur Background FPS 120.
Состав включённых HUD соответствует исходным раскладкам; не-HUD модули выключены.
Player Model и Fake FPS выключены во всех 21 профилях.

## Дополнительные клиентские сценарии — 3 файла

- `client_modules_off_hud_off.Phaze` — все переключаемые модули выключены.
- `client_all_modules_hud_off.Phaze` — остальные модули включены, HUD выключены.
- `client_all_modules_blur_gradient_rounding_x3.Phaze` — все модули, кроме
  Player Model/Fake FPS, включены; HUD 3× с максимальными эффектами.

**Внимание:** в обычном клиенте нет тестовых защит. Стресс-конфиги включают
Tape Mouse и другие автоматические модули, а также Discord RPC. Они могут
разрушать блоки, выполнять действия, отправлять сообщения и менять камеру.
Используйте их только в отдельном тестовом мире, не на основном сервере.
Фиксация камеры и блокирование действий не являются частью `.Phaze`-конфигов.

## Использование

Скопируйте нужные `.Phaze` в `Phaze/configs` своей Minecraft-инстанции и
загрузите выбранный профиль через меню конфигов. Эта папка создана отдельно;
исходные конфиги Prism автоматически не изменялись и не заменялись.
